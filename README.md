# ai

My setup for AI coding agents: skills, agents, hooks and tools. Mostly built for [Claude Code](https://code.claude.com), but I keep things tool-neutral where I can.

| What | Where |
|---|---|
| A three-line Claude Code statusline: model, effort, context, rate limits, folder + git, session | [`statusline/`](statusline/) |

## Usage

Clone it and symlink what you want into place. Each folder's README has the details.

```sh
git clone https://github.com/selrond/ai
```
